🆘 COMMON SETUP ISSUES
───────────────────────────────────────────────────────────────────────────────

❌ ISSUE: "Python not found"
   SOLUTION: 
   1. Download from https://www.python.org
   2. Install Python 3.11+
   3. Check "Add Python to PATH" during installation
   4. Restart your terminal

❌ ISSUE: "ModuleNotFoundError: No module named X"
   SOLUTION:
   1. Make sure venv is activated
   2. Run: pip install -r requirements.txt
   3. Wait for all packages to install (can take 5-10 minutes)

❌ ISSUE: "No audio detected"
   SOLUTION:
   1. Run: python mic_check.py (lists all microphones)
   2. Note your device number
   3. Run: set DEVICE_ID=<your_number>
   4. Then: python realtime_transcriber.py

❌ ISSUE: "Cannot connect to ws://localhost:8765"
   SOLUTION:
   1. Make sure realtime_transcriber.py is running
   2. Check it's in a separate terminal and NOT stopped
   3. Check Windows Firewall isn't blocking port 8765

❌ ISSUE: "Port 8765 already in use"
   SOLUTION:
   Kill the existing process:
   - Windows: tasklist /v | findstr python
   - Then: taskkill /PID <PID> /F
